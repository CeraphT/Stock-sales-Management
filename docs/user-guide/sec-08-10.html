Mouvements de stockStock movements

Le stock ne se tape jamais « à la main » : il change par des mouvements tracés. Réception d'une livraison (nouveau lot), ajustement (casse, perte) avec un motif, ou retour au fournisseur. Stock is never typed in "by hand": it changes through tracked movements. Receiving a delivery (new batch), adjustment (breakage, loss) with a reason, or return to the supplier.

  1. Réceptionner : Achats → Réceptionner du stock → cherchez ou scannez le produit → remplissez le lot → Réceptionner. Depuis un bon de commande, utilisez plutôt Réceptionner sur la ligne (section 11).Receive: Purchasing → Receive stock → search or scan the product → fill the batch → Receive. From a purchase order, use Receive on the line instead (section 11).
  2. Ajuster : fiche produit → ✏️ Ajuster → choisissez le lot → variation (+ ou −, ex. −3 pour de la casse) → motif obligatoire → Appliquer l'ajustement. Un lot ne peut pas passer sous zéro.Adjust: product → ✏️ Adjust → pick the batch → change (+ or −, e.g. −3 for breakage) → reason required → Apply adjustment. A batch can't go below zero.
  3. Retour fournisseur : fiche produit → ↩️ Retour fournisseur → lot → quantité (au plus le stock du lot) → motif (abîmé, périmé, erreur) → Retour fournisseur.Return to supplier: product → ↩️ Return to supplier → batch → quantity (at most the batch stock) → reason (damaged, expired, wrong item) → Return to supplier.
📶
Réceptions, ajustements et comptages fonctionnent aussi hors ligne sur l'application bureau et sur mobile : ils sont envoyés au serveur au retour de la connexion.Receiving, adjustments and counts also work offline in the desktop app and on mobile: they're sent to the server when the connection returns.

Comptez le stock réel et corrigez les écarts en une fois, enregistrez tout un stock existant depuis un fichier Excel, et imprimez des étiquettes avec code-barres. Count the real stock and fix the differences in one go, register a whole existing stock from an Excel file, and print barcode labels.

📋 Enregistrement de stock en masseBulk stock registration

1. ⬇ Télécharger le modèle Excel. 2. Remplissez-le (nom, code-barres, catégorie, prix, seuil, lot, péremption AAAA-MM-JJ, quantité) puis ⬆ envoyez-le ou collez les lignes. 3. Vérifier les lignes : prêtes ✅ ou en erreur ❌. 4. Enregistrer N articles. Un produit existant (même code-barres, sinon même nom) est réapprovisionné ; les autres sont créés.1. ⬇ Download the Excel template. 2. Fill it (name, barcode, category, prices, threshold, batch, expiry YYYY-MM-DD, quantity), then ⬆ upload it or paste the rows. 3. Check rows: ready ✅ or error ❌. 4. Register N items. An existing product (same barcode, else same name) is restocked; the others are created.

Passe par la fenêtre d'impression (ou Enregistrer en PDF).Search products, set the number of copies, then 🖨 Print. 50 × 30 mm labels: name, price and barcode. A product with no barcode is flagged.
