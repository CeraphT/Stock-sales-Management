Hors ligne & synchronisationOffline & sync

Coupure d'internet ou de courant : la boutique continue. L'application bureau et le mobile gardent une copie des données sur l'appareil, vendent et enregistrent hors ligne, puis envoient tout au serveur dès que la connexion revient. Internet or power outage: the shop keeps going. The desktop app and mobile keep a copy of the data on the device, sell and record offline, then send everything to the server as soon as the connection returns.

  1. Synchroniser à la main : 🔄 dans l'en-tête (web, bureau) ou depuis l'Accueil (mobile). L'application envoie d'abord vos ventes et opérations, puis télécharge les nouveautés. Un message indique le résultat : « Synchronisé · N éléments mis à jour · N envoyé(s) ».Sync by hand: 🔄 in the header (web, desktop) or from Home (mobile). The app first sends your sales and operations, then downloads updates. A message shows the result: "Synced · N items updated · N sent".
  2. Si deux appareils hors ligne vendent le même dernier article : le stock d'un lot peut passer en négatif. Le tableau de bord affiche alors « Réconciliation requise » ; le gérant corrige le stock (section 4).If two offline devices sell the same last item: a batch can go negative. The dashboard then shows "Needs reconciliation"; the manager fixes the stock (section 4).
  3. Une modification refusée par le serveur (ex. donnée déjà modifiée ailleurs) est annulée sur l'appareil et signalée.A change refused by the server (e.g. data already changed elsewhere) is undone on the device and reported.

Données & maintenanceData & maintenance

Réservé au gérant. Sauvegardes de l'appareil, restauration, et remise à zéro en cas de problème. Managers only. Device backups, restore, and a full reset if something goes wrong.

💾 Sauvegarde automatiqueAutomatic backup

Chaque jour vers 2 h (ou au premier lancement suivant), 14 jours conservés, sur l'application installée. « Lancer la sauvegarde maintenant » si besoin.Every day around 2 AM (or at the next launch), 14 days kept, in the installed app. "Run a daily backup now" if needed.

⬇️ Sauvegarder les donnéesBack up data

Une copie complète de ce qui est sur l'appareil, dans le dossier Téléchargements. Gardez-la en lieu sûr.A full copy of what's on the device, in the Downloads folder. Keep it somewhere safe.

♻️ RestaurerRestore

Choisir le fichier → vérifier le contenu par type de données → « Ajouter les nouveautés » ou « Remplacer la sélection » → éventuellement envoyer les ventes restaurées au serveur. Une sauvegarde d'une autre entreprise est refusée.Choose the file → review the contents per data type → "Add new only" or "Replace selected" → optionally send the restored sales to the server. A backup from another business is refused.

🧹 RéinitialiserReset

Efface les données de cet appareil seulement et vous déconnecte ; les données du serveur sont intactes et se rechargent à la connexion. Synchronisez d'abord : une vente non envoyée serait perdue.Wipes this device only and signs you out; server data is safe and reloads at sign-in. Sync first: an unsent sale would be lost.
