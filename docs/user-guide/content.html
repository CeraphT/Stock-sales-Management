01 · Prise en mainGetting started

Connexion & création de compteSign in & create an account

Un seul compte par numéro de téléphone, pour toutes vos boutiques. L'écran est le même sur le web, l'application bureau et le mobile. One account per phone number, for all your shops. The screen is the same on web, desktop and mobile.

Pas à pasStep by step

  1. Créer un compte : onglet Créer un compte → votre nom, votre téléphone, un mot de passe (6 caractères minimum) → Créer mon compte. Si le numéro a déjà un compte, connectez-vous plutôt.Create an account: Create an account tab → your name, phone and a password (6+ characters) → Create my account. If the number already has an account, log in instead.
  2. Se connecter : téléphone + mot de passe → Se connecter. Vous arrivez sur « Mes boutiques ».Log in: phone + password → Log in. You land on "My shops".
  3. Une boutique reste ouverte : à la réouverture de l'application, la dernière boutique utilisée se rouvre directement, même sans internet.Your shop stays open: when you reopen the app, the last shop you used opens directly, even offline.
🛡️
Super-admin : si votre numéro ouvre aussi un compte super-admin avec le même mot de passe, l'application vous demande où aller : Mes boutiques ou Console super-admin.Super-admin: if your number also opens a super-admin account with the same password, the app asks where to go: My shops or Super-admin console.

Sur mobile : même écran, avec les onglets Se connecter / Créer un compte en haut de la carte.On mobile: same screen, with the Log in / Create an account tabs at the top of the card.
